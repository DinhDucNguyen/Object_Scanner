## Data Flow

1. User interacts with View (Activity/Fragment).
2. View calls a method on the ViewModel.
3. ViewModel communicates with `AppRepository` to fetch/send data.
4. `AppRepository` decides to use Local Storage (`TokenManager`) or Network (`ApiService`).
5. Success/Error responses are returned to the ViewModel, which updates LiveData/StateFlow.
6. The View observes LiveData/StateFlow and updates the UI accordingly.
